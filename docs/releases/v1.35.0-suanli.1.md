# v1.35.0-suanli.1 · 成为蒜狸小助手的「创作」

> 各版本改动见 [CHANGELOG.md](../../CHANGELOG.md)。

本版把插件并入蒜狸小助手，成为侧栏的一级入口「创作」。渠道、密钥与模型都不再由插件
自己配置：登录小助手之后，模型清单来自部署网关的能力清单，密钥由宿主凭据服务持有。

## 入口与外观

- **侧栏「创作」**：插件只通过外壳自己的两个座位出现（侧栏入口行与中心列的键控座位），
  之前接管外壳 DOM 的那条路径整套删除。历史列回到工作台自己的三栏里。
- **去品牌**：字标、GitHub 链接、插件自更新全部移除；图标换成与包一致的线性图形；
  界面文案统一为「创作」。

## 模型与密钥

- **渠道只来自网关能力清单**：宿主读取并缓存 `/v1/ov/capabilities`，插件按目录生成唯一
  一条渠道，默认模型按「上次的选择 → 目录默认项 → 第一条」回退。
- **密钥不落在插件里**：由宿主凭据服务持有，每次提交前重新解析；插件设置与数据目录里
  都搜不到它。
- **状态条**说明目录现在是什么状态（未登录、未实名、限流、连不上、没有可用模型），
  没有可用模型时生成按钮禁用并给出同一份原因。
- **Agent 面瘦身**：系统提示是 236 字的固定文本，不再随目录变化；模型名、玩法与参数由
  只读工具 `list_media_models` 按需回答，避免每次目录刷新都打掉提示缓存。

## 移除

- 第三方渠道与其协议分支（Agnes、Seedream、grok-imagine、nanobanana、glm-image、
  Qwen/DashScope、MiniMax image-01、Google native、qwen-draw、OpenRouter）全部删除，
  只保留 h3 族与通用 OpenAI 兼容路径。
- 订阅登录、对象存储同步、内置渠道预设、插件自己的提示词增强接口一并删除；提示词增强
  与画布轻技能改用宿主对话面板里选定的那个模型。
- 旧设置里的明文密钥在升级后第一次启动即被清空（幂等，只清密钥不动其它字段）。

## 升级

无需手工配置：升级后打开「创作」，已登录的账号会直接看到自己的模型。若状态条提示未登录
或未实名，按提示在宿主里处理即可。画布、画廊、模板与历史数据保持不变。
