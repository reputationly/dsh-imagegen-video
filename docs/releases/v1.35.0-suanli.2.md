# v1.35.0-suanli.2 · 安装时不再带进 React

> 各版本改动见 [CHANGELOG.md](../../CHANGELOG.md)。

本版修正 1.35.0-suanli.1 验收中发现的问题，不改界面结构。

## 安装

- **发行包不再声明浏览器端依赖**：`@xyflow/react`、`lucide-react`、`three` 早已打进
  `lib/client.js`，现在改为构建期依赖。宿主用 npm 安装时不会再连带装上一份 React，
  浏览器端继续使用宿主自己的那一份。

## 模型与密钥

- **退出登录后不再用旧密钥提交**：每次提交前现取的密钥为空时就按空提交，由网关答复未授权，
  不再回落到渠道里留着的上一个值。
- **Agent 按模型名也能选中模型**：`list_media_models` 报的是模型名，生成工具现在同时认
  模型名和展示名。
- **提示词润色与商品文案按调用现取对话模型**：宿主的对话服务晚于路由挂载时也能用。
- **未实名、未授权也有刷新按钮**：在网关完成实名后点刷新即可重读目录，不用重启。

## 升级

无需手工操作。
